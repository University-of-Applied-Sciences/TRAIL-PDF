# Usage

This document describes the main user flows and how to use the web UI and API.

## Frontend (UI)
- Open the app in your browser (see `docker-compose` or local dev ports).
- Upload a PDF via the `PDF Konvertierung` panel.
- Select a file from the list and set `Startseite` / `Anzahl Seiten` as needed.
- Optionally set `API Delay (s)` for throttling (saved to `localStorage`).
- Click `Konvertierung starten` — the UI opens a Server-Sent Events (SSE) connection and shows `Seite x von y wird konvertiert...` in real time.
- When conversion completes, the frontend will download a `.html` file generated by the backend.

## Single Image Analysis
- Open `/image` (link from main screen).
- Paste an image with `CTRL+V` or upload via the button.
- Choose analysis mode (standard, table, math, code) and language.
- Click `Bild analysieren` — result contains generated alt-text.

## API overview
- `GET /api/health` — health check.
- `POST /api/files/upload` — upload a PDF file.
- `GET /api/files/` — list uploaded files.
- `POST /api/convert/` — non-streaming conversion endpoint (returns HTML response).
- `GET /api/convert/stream/{filename}` — SSE streaming conversion (progress events and final HTML returned base64 in a `complete` event).
- `POST /api/images/process` — analyze single image and return alt-text.

## SSE events format
Client receives JSON payloads via SSE `data:` strings. Event types:
- `status` — general status messages
- `progress` — { type: 'progress', current: <n>, total: <m>, message: <string> }
- `complete` — contains `html` as base64 and `filename`
- `error` — error message

Example SSE handler: parse JSON from `event.data` and act on `type` field.

## Troubleshooting
- If conversions fail with rate-limit errors, increase `API Delay (s)` in the UI or set `API_DELAY` env var.
- Check backend logs for API error responses from OpenAI.
